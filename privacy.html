SNS Autopost 개인정보처리방침

시행일: 2026년 10월 11일

SNS Autopost는 운영자(Chloe)가 직접 만든 글과 영상을 운영자 본인의 쓰레드 · 인스타그램 · 유튜브 계정에 예약 시간에 올리기 위해 쓰는 개인 도구입니다. 일반 사용자를 받지 않으며, 다른 사람의 계정이나 정보에는 접근하지 않습니다.

1. 이용하는 정보

  • 연결한 계정의 기본 정보 (계정 이름 · 유튜브 채널 이름) — 올바른 계정에 연결됐는지 확인하는 데만 씁니다.
  • 게시 권한 (예: 유튜브 동영상 업로드) — 운영자가 승인한 게시물을 올리는 데만 씁니다.
  • 게시 결과 (게시물 링크 · 처리 상태) — 게시가 됐는지 기록하는 데만 씁니다.

2. 보관

연결 토큰은 GitHub Actions의 암호화된 저장소(Secrets)에만 보관하며, 화면이나 공개 파일에는 저장하지 않습니다. 게시할 글과 결과 기록은 운영자의 GitHub 저장소에 보관합니다.

3. 제3자 제공

정보를 판매하거나 다른 사람에게 제공하지 않습니다. 게시물은 운영자가 선택한 플랫폼(Meta · Google/YouTube)에만 전송됩니다.

4. 연결 해제 · 삭제

Google 계정의 서드 파티 연결 관리에서 SNS Autopost 접근을 언제든 해제할 수 있습니다. 해제하면 이 도구는 해당 계정에 더 이상 접근할 수 없습니다.

5. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

6. 문의

Google 동의 화면에 표시되는 지원 이메일로 문의할 수 있습니다.

Summary (English)

SNS Autopost is a private tool used only by its operator to publish the operator's own posts and videos to the operator's own Threads, Instagram and YouTube accounts at scheduled times. It reads only basic account information (account or channel name) to confirm the right account is connected, and uses upload permission only for posts the operator has approved. Tokens are kept in encrypted GitHub Actions secrets. No data is sold or shared with third parties. Access can be revoked at any time from Google Account permissions. This tool uses YouTube API Services; the YouTube Terms of Service and Google Privacy Policy apply.
